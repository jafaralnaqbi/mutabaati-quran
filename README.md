# متابعتي مع القرآن

صفحة ويب عربية خفيفة لتوثيق الإنجاز القرآني في ستة مجالات: الحفظ الجديد، ومراجعة القديم، وتثبيت المراجعة، والتلاوة، والاستماع، والقراءة على شخص.

إعداد: جعفر النقبي

## المزايا

- تسجيل سريع للإنجاز، والتاريخ يُملأ تلقائيا بتاريخ اليوم (مع عرض التاريخ الهجري).
- وصف المقدار بالآيات أو الصفحات أو الأجزاء، وبالدقائق للاستماع؛ ويُحسب المقدار تلقائيا من النطاق.
- مستويات إتقان يقدّرها المستخدم بنفسه، وقائمة «مقاطع تحتاج إلى تثبيت».
- تقويم شهري، وإحصائيات أسبوعية وشهرية وتراكمية لكل نشاط بوحداته دون خلط.
- سجل كامل قابل للتصفية والتعديل والحذف.
- تصدير البيانات واستيرادها بملف JSON (دمج أو استبدال).
- تعمل دون إنترنت، ويمكن إضافتها إلى الشاشة الرئيسية للهاتف.

## الخصوصية

لا تحتاج الصفحة إلى حساب، ولا ترسل أي بيانات إلى خادم. تُحفظ التسجيلات في متصفح المستخدم (IndexedDB)، ولذلك يُنصح بتصدير نسخة احتياطية بين حين وآخر.

## البنية التقنية

موقع ثابت من ملف `index.html` واحد (HTML وCSS وJavaScript دون مكتبات خارجية)، مع `manifest.webmanifest` و`sw.js` للعمل دون اتصال. يُنشر على GitHub Pages أو أي استضافة للملفات الثابتة تدعم HTTPS.

ترقيم الصفحات بحسب مصحف المدينة النبوية (604 صفحات).
